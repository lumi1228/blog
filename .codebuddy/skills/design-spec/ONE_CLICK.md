# 🎨 AI 样式规范生成器

> **一键生成前端样式规范体系，让 AI 在任何项目中稳定输出符合规范的样式代码**

---

## 📝 复制下方提示词，粘贴即用

```
为当前项目建立前端样式规范体系，让 AI 稳定输出符合项目规范的样式代码。

生成以下文件：
1. design-spec.md（项目根目录）- 样式规范文档
2. skills/design-spec/SKILL.md - AI 工作流与规范应用指南

### design-spec.md 必须包含：
- 技术栈与样式系统（框架、CSS方案、UI库）
- 设计风格定位（视觉风格描述）
- 颜色系统（真实的颜色变量映射表）
- 排版系统（字体族、字号、行高）
- 布局与间距（响应式断点、圆角规范）
- 动效系统（过渡时长、缓动函数、关键帧）
- 公共组件库（实际存在的组件及其样式特征描述）
- 特殊内容样式（如 Markdown 渲染、代码高亮）
- 无障碍规范（焦点样式、ARIA、颜色对比度）
- **维护更新规则**（A级必须更新 / B级建议更新 / C级无需更新）
- 附录：快速查询表（常用变量、样式组合 Pattern）

### skills/design-spec/SKILL.md 必须包含：
- **何时使用**：样式开发、UI实现、组件样式调整时自动应用
- **工作流程**：
  1. 读取 design-spec.md 相关章节
  2. 样式开发（优先使用变量、复用组件模式）
  3. 动效与过渡（使用标准时长和缓动函数）
  4. 无障碍检查（焦点样式、ARIA）
  5. **规范更新判断**（A/B/C 三级自动判断）
- **反模式**：5+ 个示例（避免硬编码颜色、不一致圆角等）
- **使用示例**：3+ 个实际案例

### 核心要求：
✅ 基于当前项目**真实代码**生成（不要用占位符 #000000）
✅ 提取**真实的颜色变量、字体定义、公共组件**
✅ 维护规则**具体可执行**（有明确的 A/B/C 级示例）
✅ 规范文档 ≥ 400 行，公共组件 ≥ 5 个

### 维护更新规则（核心）：
- **A 级（必须更新）**：新增公共组件、修改全局颜色/字体变量、改变主题规则
- **B 级（建议更新）**：局部样式模式升格为通用规范（3+ 页面复用）
- **C 级（无需更新）**：单页面微调、bugfix、一次性活动样式

立即执行，逐步生成。
```
